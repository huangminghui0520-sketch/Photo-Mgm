# Photo-Mgm 使用教程

高速公路巡查照片分类工具 —— 根据巡查日志，把当天拍摄的照片自动归类到对应巡查事件，最后导出「分类照片 + 台账 Excel」压缩包。

## 界面总览

App 底部有三个页签：

| 页签 | 作用 |
|------|------|
| **设置** | 选巡查日期、添加照片源目录、设置输出目录、选文件夹命名方式 |
| **日志** | 粘贴巡查日志文本 → 解析出事件清单 |
| **预览** | 查看/调整照片归类 → 导出压缩包 |

整体流程：**设置 → 日志 → 预览 → 导出**，按顺序操作一次即可。

---

## 第一步：设置

### 1. 选择巡查日期
- 点击「巡查日期」卡片，在日历中选择**需要处理照片的那一天**（跨日加班时，末条日志时间会自动作为窗口终点）。
- 选好后后台会自动开始粗筛（按文件名日期过滤）→ 精读（读取照片 EXIF 时间与 GPS），无需手动操作。

### 2. 添加照片源目录（可多个）
- 点击「添加照片目录」，通过系统文件夹选择器选择照片所在目录（如 DCIM/Camera），可重复添加多个源目录。
- 添加或移除目录后会自动重新筛选。
- 添加后目录会持久化保存，App 重启后仍然有效。

### 3. 设置输出目录（导出必填）
- 点击「选择输出目录」，选择导出文件的保存位置。
- **未设置输出目录时无法导出**，导出会提示先设置。

### 4. 事件分类文件夹命名
两种命名方式：
- **事件类型**：文件夹名只含事件类型（如 `交通事故处置`）
- **日期 + 事件类型 + 巡查日志内容**（推荐）：如 `20260908_交通事故处置_发现路面障碍物`

> 文件夹名中的非法字符（`\ / : * ? " < > |`）会自动替换为 `_`，日志内容超长会自动截断。

---

## 第二步：日志解析

1. 切到「日志」页签。
2. 点击「**粘贴导入**」，把当天巡查日志文本粘贴进去（每行一条；支持在弹窗中修改后「追加到日志」）。
3. 在日志编辑框确认内容无误（可滚动编辑）。
4. 点击「**解析日志**」。

解析结果会显示：
- 巡查人员、记录人、车牌
- 解析出的事件数量
- 每条事件的类型、时间、地点（桩号含方向，如 `北行K123+000M`）、描述
- **未识别行**会标红提示行数，可在上方文本中修正后重新解析

> 提示：日志内容按每行一条记录解析，支持「接报→到达→处理」多时间段事件；无时间的事件会进入待定事件区，不自动归类照片。

---

## 第三步：预览与调整

切到「预览」页签：

### 1. 生成分类
- 资料就绪后点击「**生成分类（GPS 分组 + 事件归类）**」。
- 系统按 GPS（50 米内合并一组）+ 日志时间窗口自动归类照片。

### 2. 事件卡片
每个事件卡片显示：类型、时间、地点、描述、照片数量、台账标记状态。
- **点击卡片**打开该事件的照片管理弹窗：
  - 3 列缩略图网格，**点击缩略图即可多选**（选中项有高亮边框+对勾）
  - 顶部操作栏：已选数量、**批量移动**、**批量移除**（仅移出事件，不删源文件）、**台账标记**（选中单张时可选 照片1/照片2 槽位）、清空选择
  - 批量移动时弹出目标事件列表（带搜索框），点击目标事件即完成移动
- 顶部**搜索栏**可按事件类型/编号/地点/描述模糊过滤事件卡片。

### 3. 需要人工核对的情况
- **时间穿插**：事件时间存在交叉（如接报后途中又遇突发事件）时，卡片会提示「点击核对相关事件」，请人工确认照片归属。
- **待定事件区**：无时间的日志事件在此区域，照片不会自动归入，需手动移入。
- **未匹配照片池**：未能归入任何事件的照片在这里，可像事件照片一样多选批量移动。

### 4. 手动移动照片
- 在事件照片弹窗中多选 → 「批量移动」→ 选择目标事件。
- 在未匹配池同样可多选后移动到指定事件。

---

## 第四步：导出压缩包

1. 点击「**导出压缩包（照片+台账）**」。
2. 进度条完成后提示 `ZIP 导出：成功 N / 失败 0 + 台账Excel`。
3. 产物在**输出目录**下，文件名为 `照片分类_yyyyMMdd.zip`，内含：
   - 每个事件一个文件夹（按设置的命名方式），存放该事件分类好的照片（照片从源文件复制，源文件不被改动）
   - `未分类/` 文件夹：未匹配照片
   - `巡查台账_yyyyMMdd_HHmmss.xlsx`：Excel 台账

### Excel 台账说明
- 6 列：序号 / 日期 / 地点 / 日志内容 / 照片1 / 照片2
- 每事件一行；照片1=该事件最早拍摄照片、照片2=最晚拍摄照片（4:3 缩略图嵌入单元格，可人工在预览页通过「台账标记」调整）
- 日志内容列自动换行，可直接用 WPS / Excel 打开归档

## 常见问题

| 问题 | 处理 |
|------|------|
| 选择日期后没有照片 | 确认源目录已添加、当天照片文件名含日期（如 IMG_20260908_…） |
| 导出提示无输出目录 | 回「设置」页选择输出目录 |
| 照片归类不准确 | 属正常情况：时间穿插/跨事件场景需在预览页人工移动照片 |
| 换手机/重装后源目录丢失 | 需重新添加源目录并授权 |
